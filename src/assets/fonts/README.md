# 代码字体

`JetBrainsMono-Regular.woff2` 是 [JetBrains Mono v2.304](https://github.com/JetBrains/JetBrainsMono/tree/v2.304) 的未修改原件：`fonts/webfonts/JetBrainsMono-Regular.woff2`。许可见相邻 `JetBrainsMono-OFL.txt`；网页构建同时将许可复制到 `licenses/`，随 APK 和页面资源包交付。

DSH 原默认代码字体列表已经包含 `JetBrains Mono`。Android 的 `Courier` 别名实际会落到 `Cutive Mono`；随包提供字体让原列表在手机上解析到开发用等宽字体，无需下载电脑插件资源或请求字体 CDN。手机/Remote使用同一字体文件和原DSH字号；用户自定义字体仍排在默认列表前。没有复制受限的系统字体，也没有改动DSH组件或默认字体列表。
