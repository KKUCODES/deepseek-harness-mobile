# 长聊天大响应传输

状态：2026-10-23，本地验收完成，配套preview.7/插件0.1.87已公开发布，[云端签名及匿名下载核验](../releases.md#已核验范围)通过；公共中转升级尚待登录信息。实现：[KKC-75](https://linear.app/kkcodes/issue/KKC-75)；发行与公共中转升级：[KKC-76](https://linear.app/kkcodes/issue/KKC-76)。独立分支不合并 `feature/plugin-adaptation`，不修改 DSH 本体。

## 实现

`RemoteClient` 与共享协议重组器接收通用分块，完成顺序、字节数、摘要、UTF-8、JSON 校验后才交给原业务回调。首次快照、历史分页和实时大事件共用同一路径，保留原事件顺序；原生 `RemoteBridge` 放行严格校验的 `responseAck`，单帧接收上限仍为 2 MiB。

分块需网关与插件都宣告版本1后逐请求启用。旧中转或旧插件保持原格式；超限显示明确的配套升级提示。未修改普通聊天配置、历史格式或 SDK 分页策略。

断线、重连、取消和撤权清除片段与旧能力，重新协商并读取新数据；不跨连接拼接，不自动重发写操作。完成事件的慢消费者队列也改为连接共享字节预算，避免多个订阅分别占满内存。

每条32 MiB、并发4条、在途声明合计64 MiB、空闲30秒、总时限120秒；超过边界明确失败。完整协议、旧端矩阵及升级顺序见[中转说明](../../../backend/docs/response-chunks.md)。字节预算不等同于解析后的手机堆内存上限。

## 验证

- [跨端发送器与手机入口测试](../../tests/remote-response-chunks.test.mjs)：大页/首快照/连续大事件、包络越界、中文与跨块emoji、四块背压、取消/超时/重连、缺块/重复/重排/损坏、资源预算和慢消费队列。
- [实际 Android 驱动](../../scripts/verify-rc21-android.mjs)：使用 `DSHM_ANDROID_SERIAL` 选择设备；只清理专用测试UID，原生配对、批准后从正式Remote列表打开合成长聊天，加载历史并重载恢复。桥上只审计类型、声明字节和帧大小，不记录正文或凭据。此专项不调用模型。
- 共享协议/网关与插件需先本地构建；手机执行 `npm test`、`npm run build:web:official`，然后按[开发指南](../development.md)构建自有 Android 调试包及 lint。

preview.7与插件0.1.87配套提供本修复，构建固定共享协议提交 `94183d08ccbb8752d14c819608d79fe3870a9a60`。三端配套更新前，旧连接的大响应限制仍然存在。

本轮：532项单测、官方Web构建、自有Android构建/lint通过；Android12模拟器的专用UID在原官方rc.2上通过2.55MB首快照、2.52MB历史页、重载列表后重新打开同一聊天，以及原生通知/主题和撤权，帧最大87,525字节。实际内容为60回合合成工具输出；无模型调用，无页面异常或失败插件。更大正文渲染性能和真机并非本轮通过范围；实时大事件在生产中转/Relay/手机客户端联调中验证。失败夹具、驱动修正和完整证据见[三端结果](../../../backend/docs/response-chunks.md#本轮结果)。
