## 页面地图

已确认：普通启动进入空白普通聊天；侧边抽屉访问历史和 Remote；不设多电脑选择页。插件有明显入口。以下提案将插件、设置也放入抽屉，具体顺序在原型中审阅。

```text
普通聊天（默认空白新聊天，也可打开历史）
├─ 侧边抽屉
│  ├─ 新聊天
│  ├─ 搜索 / 最近聊天
│  ├─ Remote
│  ├─ 插件
│  └─ 设置
├─ 输入区：文字 / 相册优先的附件入口 / 独立发送按钮
├─ 消息操作：复制 / 重新生成 / 从此继续另一聊天
└─ 其他操作：改名 / 分享 / 编辑 / 删除等

Remote（当前仅一台电脑）
├─ 未绑定：连接电脑 / 领取链接或扫码 / 等待电脑批准
├─ 无法连接：连接状态 / 重试 / 重新配对入口
└─ 已连接：任务列表
   ├─ 等我处理 / 正在进行 / 其他任务
   ├─ 搜索 / 工作区筛选 / 归档与恢复
   ├─ 新聊天 → 在项目中工作 → 选择已有工作区
   ├─ 远程聊天
   │  ├─ 详细过程 / 工具结果 / 思考 / 历史
   │  ├─ 输入、附件、排队、停止
   │  ├─ 审批 / 助手提问 / 计划确认
   │  ├─ 子任务 / 目标 / 定时与后台任务 / 工作流
   │  └─ 文件、代码修改、只读命令详情、预览
   └─ 当前电脑信息 / 连接与授权状态 / 电脑设置

插件
├─ 手机插件：列表 / 兼容说明 / 安装 / 启停 / 设置
└─ 电脑插件：列表 / 设置 / 获准后的安装、升级与卸载

设置
├─ DeepSeek Key / 普通聊天模型设置
├─ 外观、语言与阅读设置
├─ 提醒设置
└─ 本地历史导入导出 / 存储与缓存 / 诊断与版本
```

这里展示的是入口归属，不要求每个条目都新建一个全屏页面。低频管理操作优先放在对应页面菜单里；不因入口不常驻就删除功能。插件明确标注“手机”或“电脑”，不会把电脑插件误当成本地普通聊天可用插件。

## 返回与恢复

```mermaid
flowchart LR
    R[远程聊天] -->|返回| T[任务列表]
    T -->|返回| C[普通聊天]
    C -->|返回| B[App 切到后台]
```

图中返回仅在键盘、菜单和底部窗口均收起后生效；有临时界面打开时，先关闭当前临时界面，不直接跳页。

| 情况 | 行为 | 依据 |
| --- | --- | --- |
| 完全关闭后的普通启动 | 空白新聊天；不删除历史和已保存草稿 | 已确认 |
| 切后台再回来 | 保留离开时页面、聊天、草稿和阅读位置 | 已确认 |
| 远程聊天返回 | 任务列表；再返回普通聊天 | 已确认 |
| 普通聊天根页返回 | App 退后台 | 已确认 |
| 点击有效系统通知 | 进入对应远程任务，获取最新状态；不直接批准或执行 | 通知设计规则 |
| Remote 返回普通聊天 | 恢复本次离开普通聊天时的页面与草稿；没有原页面则空白聊天 | Agent 提案，避免切换丢失上下文 |
| 远程聊天回任务列表 | 保留列表筛选及阅读位置 | Agent 提案 |

完全重新启动仍可恢复有效绑定并尝试重连；连接不成功不阻断普通聊天。空白新聊天只在实际形成内容时需要持久记录，避免每次启动堆积空白历史（Agent 提案）。

## 六条核心流程

### 1. 普通聊天与历史

普通启动 → 空白聊天 → 未配置 Key 时进入配置 → 返回草稿 → 输入/添加模型支持的附件 → 点发送 → 流式回复。

回车只换行。思考过程默认折叠。生成时可以继续写草稿，但不自动排队发送；停止按钮与发送操作应明显区分。回复完成后直接提供复制、重新生成、从此继续另一聊天，其他操作放菜单（按钮排列待原型审阅）。

历史通过抽屉按最近使用排列并支持搜索；打开历史保持原会话归属。编辑/重新生成/分支的旧版本应保留，不静默覆盖原回复；具体版本切换控件在原型中展示。

### 2. 首次连接电脑

抽屉 Remote → 未绑定页 → 粘贴链接或扫码 → 领取成功 → 等待电脑核对批准 → 自动检查批准结果 → 任务列表。

等待期间可返回普通聊天，不让整个 App 停在配对页。过期、已被领取、被拒绝要有不同提示；未批准不显示任务。只有一台电脑，不提供多电脑切换。更换绑定应单独明确操作，不能在新链接进入时静默覆盖已有身份（Agent 提案）。

### 3. 查看任务并处理问题

Remote → 优先看到“等我处理”“正在进行” → 点任务 → 看接近 DSH 的详细过程 → 在对应位置批准/拒绝或回答问题 → 状态更新。

其他任务需要处理时显示提示条，不抢走当前页面。已由电脑处理的审批显示已处理，旧按钮失效；点击通知也是进入任务查看最新状态。手机显示状态不代表任务已经结束，以电脑记录为准。

已确认的模型交互：手机实时显示当前会话的具体模型，点击可从电脑提供的模型列表中选择；手机和电脑共享当前会话的模型设置，两端变更相互同步，不改其他会话。电脑确认选择后更新名称，下一次模型请求生效，当前请求不被中途换模型。离线展示上次确认值并禁用切换；未知结果先核对，不自动重放。当前仅完成可点击预览，真实远程协议尚需增加目录/选择操作与状态同步。

### 4. 在已有工作区开启任务

任务列表的新聊天 → 空白远程聊天页 → 页面水平与垂直中央的“在项目中工作”按钮 → 悬浮蒙层菜单 → 选择已有工作区 → 输入任务 → 发送。

每次新建都明确选择工作区，不创建工作区，不自动使用上次目录。没有工作区时提示先在电脑建立。选工作区前不允许把消息发送到未知位置；输入区是暂时收起还是保留草稿但禁用发送，在原型中比较（Agent 提案）。

### 5. 查看代码、文件与命令

聊天中的修改记录 → 底部可放大窗口 → 带增删颜色与语法高亮的对比 → 右上下载 → 下载电脑端当前最新完整文件 → 收起窗口回原聊天。

对比记录可能是较早一次修改，下载内容则明确为“最新文件”，避免将二者误认成同一版本。文件已删除、读取失败或电脑离线时给出错误，不用旧内容冒充最新文件。

命令记录 → 同样的底部窗口 → 命令、状态、摘要、工作区目录、时长、输出；只读，无手机输入命令入口。聊天交代任务与审批保留。普通文本、图片、PDF 等建议复用可放大的预览容器，具体显示按格式适配，属于待审阅布局提案。

### 6. 插件管理与连接恢复

抽屉插件 → 明确选择手机或电脑插件 → 列表与兼容状态 → 设置/启停；电脑安装、升级、卸载等仅在已获管理权限时可操作。未获权限显示原因，不假装执行成功。

上述流程已提供[独立可点击预览](./ordinary-preview/plugins-preview.md)，含 Remote 菜单电脑插件入口、安装/更新/卸载确认、兼容与依赖提示、离线/权限/失败状态。目录与权限均为虚构示例，真实接入未完成。

使用 Remote 中断线：保留已读聊天，标离线与更新时间，尝试重连；重新连接后更新快照，不重复添加消息。首次进入 Remote 就连不上：显示连接状态、重试及返回入口。发送结果未知时保留提示并核对电脑结果，不自动重发。

### 7. 手机设置

抽屉设置 → 这台手机（普通聊天、外观/语言、通知、本地数据）或电脑连接 → 对应表单/选择/确认 → 返回原页面。[设置页可点击预览](./ordinary-preview/settings-preview.md)已覆盖正常、取消及错误分支；Key 使用固定演示值，主题/语言效果范围、备份样例和真实系统接入限制见该文档。默认模型用于下一次普通新聊天，数据清理不影响 Key 或电脑绑定；Remote 重连/解绑共用预览连接状态。

## 提醒规则

- 正在看对应任务：原地更新，不重复横幅或系统通知。
- 前台但在其他页面：App 内提示条，不强制跳转。
- 后台且进程存活、连接可用：对 Remote 待审批/提问、完成和失败发标题与简短摘要通知，点击进入对应任务。
- 进程结束：不通知、不唤醒；重开尝试重连并读取最新状态。
- 普通输出片段、普通聊天回复结束和短暂断线默认不发系统通知。未给通知权限不阻断使用。

## 页面状态覆盖

| 位置 | 除正常内容外必须有的状态 |
| --- | --- |
| 普通聊天 | 未配 Key、无历史、生成中、停止、网络/额度错误、中断后恢复、附件不支持 |
| 配对 | 等待、批准、拒绝、链接过期/已用、结果不确定 |
| 任务列表 | 首次加载、无任务、筛选无结果、离线、授权失效 |
| 远程聊天 | 运行/排队/待处理/已完成/失败、历史加载、发送结果未知、其他端已处理 |
| 文件与命令窗口 | 加载、空输出、读取失败、文件删除、下载失败、输出仍在更新 |
| 插件 | 无插件、加载/更新中、不兼容、缺依赖、权限不足、启停失败 |
