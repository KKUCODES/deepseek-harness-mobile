## 核对范围与结果

| 实际入口与流程 | 结果 |
| --- | --- |
| 普通聊天 → 设置/插件 → 返回 | 两行草稿与非零阅读位置恢复；切换聊天后模型、深度思考按会话恢复 |
| 设置/插件详情 → 弹窗 → 返回 | Escape 只关闭顶层弹窗；再次返回回到上一层，插件详情失焦后同样有效 |
| Remote → 任务 → 详情 → 文件/命令 → 返回 | 文件底部/全屏关闭保持原任务；命令只读；下载产生真实下载事件，内容为完整示例文件 |
| 续聊、排队、审批、提问 | 队列保留换行，明确处理下一条；批准/拒绝及回答后旧操作不可重复使用 |
| 已有工作区新建 | 新任务进入列表，每次新建重新选择已有工作区；返回保留草稿 |
| 消息结果未知、离线、重连 | 离线不能核对或写入；重连不会自动重发，核对后消息只出现一次 |
| 列表/历史/文件/命令读取失败 | 有明确重试入口；历史去重；文件删除不提供下载，下载失败提供恢复入口 |
| 设置、Remote、电脑插件连接 | 共享连接状态；离线禁写；恢复连接保留任务和草稿；授权失效隐藏任务/电脑插件，重绑定不继承旧管理权限 |
| 375×667、360×640、375×400 | 普通聊天聚焦、附件弹窗、Remote 聊天与全屏文件无根页面横纵溢出，内容区保留内部滚动 |

## 发现并修复的问题

1. 文件/命令弹窗的 Escape 冒泡到 Remote 页面，意外返回任务列表。共用 Surface 阻止向下层导航传播。
2. 普通聊天模型和思考状态原为全局值，新聊天覆盖已有会话选择。改为按会话保存；默认模型只用于新聊天。
3. 设置和插件的返回层级不完整；点击后原按钮卸载导致焦点离开页面时，Escape 不生效。按当前可见页面处理返回，弹窗始终优先。
4. 插件页持有独立连接状态，设置断线后仍可能显示在线。统一使用 Remote 状态，解绑/授权失效清除示例管理权限，隐藏电脑列表。
5. 恢复在线场景会重建任务和会话。恢复连接只改变连接状态，保留已有任务、草稿和聊天。
6. 文件加载的迟到回调覆盖“已删除/失败”等新状态。切换状态、关闭和重新读取时取消旧计时器；历史失败/断线也取消尚未完成的历史读取。
