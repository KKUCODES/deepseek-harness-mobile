## 入口与布局

在手机项目执行 `node scripts/ordinary-preview.mjs --serve`，打开 `http://127.0.0.1:4400/`，普通聊天抽屉 → 设置。

参考 DSH `ui-settings-general/src/client/SettingsRoot.tsx` 的分类、主题和图标，手机使用全屏分组列表与逐层返回；沿用上游 Button、Switch、图标与主题变量。选择/确认使用共享底部窗口，可通过关闭按钮、遮罩或 Escape 返回；异步写入期间暂时禁用退出以避免误认为取消了已提交操作。

## 当前可以验证的流程

| 分组 | 已实现的设计预览 |
| --- | --- |
| 普通聊天 | Key 未配置/已配置状态，固定示例配置、替换、移除确认；无效 Key、额度不足、网络错误、操作失败保留原配置；默认模型选择/取消/保存，用于下一次新聊天 |
| 外观与语言 | 浅色/深色/跟随系统；设置页即时变色；简体中文/English 在样例卡切换，偏好在当前页面生命周期内保留 |
| 通知 | 系统权限允许/拒绝示例；待批准/回答、任务完成、失败三个开关；按前台当前任务、前台其他页、后台进程存活、进程结束及连接状态展示效果；点击示例通知打开对应 Remote 任务 |
| 本地数据 | 当前普通聊天数量/示例用量；备份预览及下载、示例文件校验/导入、重复 ID 跳过；清缓存、清空聊天与草稿的确认/取消/失败重试 |
| 电脑连接 | 共用 Remote 示例连接状态；未绑定入口、连接信息、离线重连、授权失效转配对、在线/离线解绑确认；解绑同步 Remote 入口 |

设置首页区分“这台手机”和“Remote”。电脑管理不返回电脑明文 Key，也不混入手机默认模型、主题或本地数据操作。默认模型保存不会立刻改变当前聊天；从首页或抽屉新建聊天时应用。

右上“设置预览场景”仅切换内存场景：Key 成功/无效/额度/网络、下一次操作失败，以及电脑在线/离线/授权失效。没有调用 API 或改变真实权限。

## 数据和系统边界

- Key 输入框只读，只能填入固定演示值；没有真实 Key 输入、存储、读回或网络验证。正式配置仍须使用现有原生安全窗口及桥接契约。
- 通知在页面内展示效果，不调用浏览器或 Android 通知权限。后台仅进程存活且连接可用时允许系统提醒；进程结束不推送、不唤醒，重开读取最新状态，不补发全部历史通知。
- 主题效果限定设置页；语言限定效果卡。全应用主题/多语言、本机系统设置跳转与 Android 生命周期留待正式接入，不能据此宣称整套界面已完成多语言适配。
- 导入只使用内置备份/损坏文件/新版本样例，不打开本机文件选择器。所有格式验证先整体完成，失败不产生部分导入；重复 ID 保留已有记录。
- 导出为当前内存普通聊天的 JSON，只取 ID、标题、分组、消息角色/正文/思考；不含草稿、Key、设备凭据、Remote 数据或插件配置。预览格式 `dshm-design-preview` 与正式 App 备份格式无关。
- 下载由本机预览服务 `POST /preview-history-export` 校验后返回 HTTP 附件，禁止缓存，不落盘请求内容。此服务只绑定 loopback；不是公网后端功能。仅运行静态构建文件不提供该下载路由，应使用 `--serve`。
- 清聊天同时清除普通聊天草稿并回到空白页；Key 配置状态、插件和电脑绑定保留。清缓存只重置演示用量。离线解绑明确说明无法确认电脑端撤销，需后续在电脑移除设备；本次不操作真实设备授权。
