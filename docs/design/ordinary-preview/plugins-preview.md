## 入口与操作

运行 `node scripts/ordinary-preview.mjs --serve`，打开 `http://127.0.0.1:4400/`：

1. 普通聊天抽屉 → 插件，默认进入手机插件。
2. Remote 连接示例电脑后 → 右上菜单 → 电脑插件，继承当前示例连接状态；退出回到原 Remote 页面。未绑定时禁用入口。
3. 手机/电脑标签分别管理各自列表。点击插件查看版本、能力说明、运行状态、组件和设置；安装入口提供示例目录。
4. 右上场景菜单可演示电脑授权/离线、列表加载/失败/为空，以及下一次操作失败。场景切换不改变真实权限；电脑连接场景与 Remote、设置页共享，恢复在线不重置任务和草稿。未绑定或授权失效时隐藏电脑列表并清除旧的示例管理权限。

手机与电脑使用同一页面组件，减少两套页面行为漂移；数据和设置按运行位置隔离。详情保留 DSH 的包名、版本、组件列表和启停开关；直接复用上游 Button、Switch 和图标，未导入依赖 Host 服务的完整管理控制器。

## 行为与边界

| 操作 | 预览行为 |
| --- | --- |
| 启停 | 等待操作结果后改变状态，在途禁用写操作；失败保留原状态 |
| 设置 | 文本/选项示例表单，保存后生效；取消或关闭丢弃未保存内容；未授权/离线只读 |
| 安装 | 确认运行位置、来源、版本和能力后添加到当前端；目录全部为虚构包名 |
| 更新 | 展示目标版本，成功后保留设置和启停状态；失败仍显示旧版本，可重新发起 |
| 卸载 | 确认移除插件及其设置，不删除聊天；不影响另一端同名插件；可从目录重新安装 |
| 无权限/离线 | 禁止电脑端写操作，保留查看；帮助引导至电脑授权，不在手机上自授予权限 |
| 兼容限制 | 需要电脑能力、版本不兼容、缺依赖分别解释；不能通过确认弹窗绕过 |
| 连接/权限在操作中变化 | 作废在途结果，显示未确认，不应用迟到成功、不自动重放 |
| 列表异常 | 加载提示、读取失败重试、空列表安装入口、搜索无结果和清除搜索 |

普通聊天目标为已声明本地能力并核验版本的可信插件；本页的“适用范围”只演示兼容信息呈现，不能当成真实兼容结论。能力说明也不代表 Cordis 可以隔离恶意代码。电脑管理权限未来需单独授予，现有生产协议尚无该能力。

状态仅在内存中保存，刷新重置；不访问普通聊天 Key、真实历史、文件、网络安装源、Cordis 或电脑插件。示例保存的阅读间距/提示词用于验证表单状态，不实际改变普通聊天渲染或输入插件。
