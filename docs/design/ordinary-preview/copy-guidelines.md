| 场景 | 约定 |
| --- | --- |
| 外观与语言 | 只保留主题、语言和效果卡；删除卡片下方开发说明和预览页脚 |
| 模型选择 | 说明何时生效、影响哪条聊天，不讲 API 接入计划 |
| 附件、工作区 | 直接提示选择照片、文件或工作区，不解释尚未实现的技术路径 |
| 插件权限 | 指明去电脑授权及如何检查结果，不展示未来权限协议的开发备注 |
| 状态反馈 | 使用“正在处理”“操作未完成，请重试”等直接表达 |
| 删除、解绑、下载 | 保留数据影响、不可撤销、离线撤销限制及最新完整文件等有用说明 |
| 预览边界 | 抽屉预览标识、状态演示工具及 Key/扫码/导入/安装等真实能力尚未接通的操作保留简短标识；不把示例操作伪装成真实执行 |
