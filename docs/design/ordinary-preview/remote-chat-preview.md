## 审阅入口

运行 `node scripts/ordinary-preview.mjs --serve`，打开 `http://127.0.0.1:4400/`。普通聊天抽屉 → Remote → 右上更多 → 预览场景 → 电脑已批准 / 已连接。也可沿用已有示例配对路径。

1. 打开“调整手机端输入框”：翻看历史、展开思考、查看工具记录，批准或拒绝本次修改。
2. 输入补充内容，回车换行；忙碌时显式加入队列，可取消排队、停止当前轮次、演示处理下一条。附件菜单使用相册/文件示例，不访问设备文件。
3. 打开“整理本周读书笔记”：选择答案或填写自己的回答。“预览状态”提供电脑端已处理、其他任务提醒、失败、历史读取失败、下次发送结果未知和断线。
4. 点代码或命令记录：底部窗口可放大/缩小；代码含增删颜色与 DSH 语法高亮，右上下载最新完整示例文件；命令显示目录、耗时、状态、摘要、输出，只读。

文件窗口中的“本次修改”与“最新完整文件”是不同版本；下载文件 `composer.latest.example.ts` 包含差异之后的 `restoreSelection` 与完整 `canSend` 函数。底部“文件预览状态”可演示加载、删除、读取失败、下载失败；命令窗口同样提供加载、持续输出、空输出和失败状态。

图标审阅修订：文件与命令窗口的放大/缩小按钮统一使用 20px 四角展开/收拢 SVG，1.7px 圆角描边，替换原字符箭头。已构建并在两个实际窗口检查图标及放大/缩小切换。

按钮状态修订：批准/提交回答原先仅覆盖背景和文字，仍继承默认 ghost 的浅色 hover/active，导致白字难辨。现明确使用 DSH Button 的 primary 类型，局部类只控制圆角；普通/Remote 发送及新建按钮同样明确类型并保留自身配色。已从实际入口检查默认、hover、hover+active、focus-visible 与离线禁用；审批悬停为 `rgb(67, 69, 74)` 配白字，禁用时不触发 hover 变色。记录在 `artifacts/ordinary-preview-evidence/button-state-checks.json`；发送按钮动效期间临时透明度与结束后稳定态分别记录，稳定态 opacity 为 1。

## 实现边界与取舍

### 会话模型双向更新（用户确认）

- 输入区显示具体模型名称，不显示“跟随电脑”。未聚焦时在输入框上方显示，聚焦时并入工具栏；两个入口打开同一个模型菜单。
- 手机与电脑操作的是**当前会话**的同一模型选择；不改其他会话或普通聊天模型。电脑更新时手机同步显示，手机切换经电脑确认后才显示新选择；从下一次模型请求生效，正在生成的请求保持原模型。
- 预览以共享会话内存状态演示手机选择、电脑事件、失败保留原值、切换中断线/结果未知及核对。未知时禁止继续提交，重连不重放切换，草稿和会话阅读状态保留。菜单明确标注示例来源。
- 源码依据：上游 `packages/client/ui-model-selection/src/client/directory.ts` 通过 `session.selectModel` 修改会话，由持久投影更新 current；`catalog.ts` 通过 `session.modelCatalog` 取得电脑列表。示例名称 DeepSeek Chat / DeepSeek Reasoner 来自上游会话模型测试，不代表用户电脑已配置的列表。
- **真实同步尚未接通**：当前 [远程协议](../../../../docs/protocol.md) 白名单未提供模型目录和选择操作。正式接入需要插件/后端开放对应操作，手机读取电脑目录和会话模型投影，并处理选择结果/断线/过期事件；不能用固定模型列表或本地乐观状态替代真实电脑响应。
- 已通过 9 条浏览器检查：手机选择、电脑事件、未聚焦显示、失败保留、离线禁改、重连不重放、草稿保留、会话隔离及返回恢复；新增 2 项状态测试，总计 6 项通过。浏览器证据 `artifacts/ordinary-preview-evidence/model-selection-checks.json`。

### 其他预览边界

- 直接复用 DSH 主题、气泡、按钮/图标、语法高亮和 TerminalBlock。普通聊天与 Remote 详情共用 [PreviewComposer.jsx](./PreviewComposer.jsx) 的双态输入与反向动画，避免复制两套行为；新建前的工作区选择页沿用上一阶段设计。
- 聊天预览独立于真实数据：采用 [remote-chat-demo.mjs](./remote-chat-demo.mjs) 的内存状态转换，[RemoteChatPreview.jsx](./RemoteChatPreview.jsx) 负责内容和详情窗口，[RemotePreview.jsx](./RemotePreview.jsx) 保存各任务状态与阅读位置。刷新重置；不请求模型、网关或电脑，不改身份与权限。
- 选择抽出共用输入框及纯状态转换，比直接在任务概览里堆叠分支多两个文件，但避免普通/Remote 动画不一致，并能独立验证重复操作、队列、未知结果等边界。没有新安装依赖或改动上游。
- 实时输出由定时示例驱动，忙碌期间补充消息需手动发送入队；示例队列在当前轮次结束后，使用“演示处理下一条”继续。正式产品的调度以电脑状态为准，预览不会假装建立真实调度服务。
- 未知结果禁止再发送，重连不会自动重发；核对示例结果后继续。离线保留草稿和聊天、显示更新时间、禁用提交与最新文件下载。任务返回恢复阅读位置；读旧内容时显示最新输出入口，不强制滚到底部。
- 已处理/已取消的审批与问题不再提供旧提交按钮。跨任务提醒只显示横幅，用户点“查看”才切换；不调用系统通知权限。最新文件不可读时不以差异版本代替。
- 下载是构建生成的静态示例完整文件，非真实电脑下载接口。浏览器实际触发下载事件；Android 下载桥、审批协议、真实附件、通知、软键盘、后台生命周期与正式产品集成仍未实现/未验收。

| 范围 | 已核验证据 |
| --- | --- |
| 两个真实入口 | 从已有任务列表进入完整详情；从新聊天选已有工作区、创建排队任务、演示执行、续写草稿、打开文件 |

| 提醒与恢复 | 跨任务横幅不抢页面，点击才跳转；原任务草稿恢复；聊天滚动位置离开/返回均为 501.33px |
| 不确定与断线 | 发送结果未知时禁用重复发送；离线禁核对；重连保留单条消息；核对后仍只有一条 |

| 普通聊天回归 | 共用输入后仍支持两行草稿、模型选择及示例发送，控制台无 error/warn |
