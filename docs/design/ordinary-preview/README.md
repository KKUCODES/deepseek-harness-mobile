## 打开预览

抽屉搜索已改为右上角搜索图标 → [独立搜索页](./search-preview.md)，进入自动聚焦，输入实时匹配标题和正文；关闭返回抽屉。以下早期抽屉内搜索框及关闭按钮检查记录已由此交互替代。

在手机项目目录运行：

```text
node scripts/ordinary-preview.mjs --serve
```

打开 `http://127.0.0.1:4400/`，以 375 × 667 审阅。仅构建可去掉 `--serve`。需要已有 npm 依赖及旁边只读的上游检出，不修改原技术验证页面或 Android APK。

## 可以体验什么

- 冷启动空白普通聊天；沿用鲸鱼标识、欢迎区、圆角输入卡。普通聊天顶栏仅保留抽屉与新聊天按钮，空白首页和历史聊天均不展示中间标题区，没有工作区或 Agent 模式选择。
- 首页与历史聊天的输入区统一吸底，保留至少 12px 或设备底部安全区间距；欢迎区位于剩余内容区域中央。页面底部不再展示预览提示文案，示例与未接模型的边界仍见本文和演示回复说明。
- 输入框参考用户提供的 ChatGPT 两态示意：未聚焦为 56px 高的单行胶囊，显示附件、草稿摘要和发送；点击文字区后展开，上方为文字区，下方为附件、模型、思考与发送。点击外部或在文字区按 Esc 收起，草稿保留；工具栏操作和模型/附件菜单不会中途折叠导致误点。未新增语音功能。
- 两态过渡采用 300ms 展开 / 240ms 收起和柔和减速曲线，卡片背景缩放、文字与按钮平移、工具栏渐显隐；同一输入节点不缩放文字。快速反向切换从当前显示位置继续，系统要求减少动态效果时直接切换。
- 左上打开覆盖式抽屉，关闭时不占聊天宽度；关闭按钮、点击外侧遮罩、Esc 均可关闭。
- 抽屉中包含新聊天、Remote、插件、可搜索的示例聊天，以及底部设置。
- 搜索标题及示例正文，支持清空与无结果提示；选择历史后自动收起抽屉。
- 当前页面生命周期内，各聊天及空白首页分别保留草稿；回车换行，显式发送。发送后新增示例历史，回复明确标注为界面演示。
- 示例回复的思考默认折叠，提供复制、重新生成提示及示例分支入口。
- 模型与思考开关仅演示选择状态；附件菜单以相册为先。Remote 进入独立预览页面，插件进入[独立管理预览](./plugins-preview.md)，设置进入[手机设置预览](./settings-preview.md)；所有底部窗口统一通过右上角关闭、遮罩或 Esc 关闭，不重复放置“返回聊天”按钮。

## 实现来源与边界

[main.jsx](./main.jsx) 直接导入 DSH 的 Button、FishLogo、图标、主题 CSS、InputBar 输入卡样式、MessageItem 气泡样式和 SidebarRoot 根样式。新增布局与交互位于 [style.css](./style.css) 和 React 预览组件；未声称复用了完整聊天业务组件或 Cordis 插件运行时。

[构建脚本](../../../scripts/ordinary-preview.mjs) 将产物写入 `artifacts/ordinary-preview/`，其中 `source-map.json` 是 esbuild 输入来源清单。上游 commit 为 `ddefc45fbc7f8e46dd73185e68295696d1297887`，核验时上游工作区无修改。

示例数据只存在内存，刷新回到空白首页并重置历史。预览不读取真实历史、Key 或设备凭据，不请求模型或 Remote，不执行文件上传/插件安装，不代表真实发送、后台恢复或插件兼容通过。真实 API 接入仍由已有技术验证项目负责，设计预览不能取代它。
