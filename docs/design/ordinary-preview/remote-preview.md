- 维护角色：DSH Mobile 项目协作 Agent。

- 依据：用户目标“按序完成 Remote 首页＋任务列表的可点击预览”、[页面地图](../页面地图与核心流程.md)、[问卷结论](../问卷结论与追问.md)、[KKC-9](https://linear.app/kkcodes/issue/KKC-9)。

## 审阅顺序

按[预览入口](./README.md)启动，打开 `http://127.0.0.1:4400/`。

1. 普通聊天左上抽屉 → **Remote** → 连接电脑。
2. 点“使用示例链接” → 继续配对 → 等待电脑批准。扫码入口仅演示扫描成功，不访问相机。
3. 点“演示电脑批准结果” → “电脑已批准 / 已连接”，进入单电脑任务首页。
4. 首页按用户提供的 ChatGPT 截图排列为居中标题、电脑名称、“项目”和“最近”列表。点击项目只看对应工作区的聊天，返回 Remote 首页；“聊天”行滚动到最近列表。底部固定搜索，右上“⋮”可筛选等我处理/正在进行/其他任务、查看归档、筛选工作区和刷新。
5. 底部新聊天 → 屏幕中央“在项目中工作” → 悬浮窗口选择已有工作区 → 输入内容 → 创建示例任务。每次新建重新选工作区，不提供创建工作区或电脑目录浏览。
6. 右上“⋮” → **预览场景** → 使用中断线，观察任务保留与禁用新建；点重连恢复。

预览场景菜单还提供：未绑定、等待、过期、已用、拒绝、结果未知、首次连接失败、授权失效、加载中、无任务、读取失败、无工作区。菜单中的预览场景是审阅工具，不是已交付的电脑设置功能。

## 设计与边界

- 单电脑，无多电脑切换。连接条展示状态与更新时间；已读任务断线后保留，首次连接重试成功前不展示任务。
- 未配对、未批准和授权失效时不展示任务。结果未知先检查状态，不自动重复领取。
- 普通聊天与 Remote 保留独立内存状态；等待批准时可回普通聊天，返回 Remote 继续等待。普通聊天草稿不会因模式切换丢失。
- 用户后续提供 ChatGPT 排版参考，首页改为“项目＋最近聊天”，行内只展示标题和时间；任务状态保留在概览与无障碍名称中，待处理/进行中/其他及归档通过更多菜单筛选。此排版替代上一版常驻分组和顶部搜索栏；点击任务返回后保留筛选和滚动位置。
- 新建页选择工作区前收起输入区，主按钮在 375 × 667 屏幕中心（约 188 × 334）；无工作区时提示先在电脑建立。此布局为本轮待审阅提案。
- 连接成功、重试、批准、任务创建均是明确标注的本地示例。没有 fetch、WebSocket、真实身份、配对领取或电脑操作；不保存链接或历史，不请求模型。刷新会重置示例。
- 任务入口现已接通[远程聊天详情预览](./remote-chat-preview.md)，覆盖示例实时输出、审批/提问、队列与文件/只读命令窗口。下表保留首页阶段验收记录；详情验收见新文档。真实扫码、远程审批协议和正式 Android 接入仍未实现。
