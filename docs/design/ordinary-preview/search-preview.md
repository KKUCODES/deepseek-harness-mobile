- 状态：独立设计预览已实现并经内置浏览器检查，等待页面审阅。
- 维护角色：DSH Mobile 项目协作 Agent。
- 最近核验：2026-09-23。
- 来源：用户提供 ChatGPT 手机搜索参考图及明确的入口、自动聚焦、实时搜索要求；[主入口](./main.jsx)、[搜索页](./ChatSearchPreview.jsx)、[搜索匹配](./chat-search.mjs)、[搜索测试](../../../tests/chat-search-preview.test.mjs)。

## 已实现交互

输入框内清除图标采用 24px 灰色实心圆与白色叉号，保留 44px 点击区域；悬停和按下只加深圆底，外侧关闭按钮保持描边样式。已在实际页面核验颜色、尺寸及清空后继续聚焦输入。

圆形需显式设置 `corner-shape: round`，否则上游全局 superellipse 会使圆底呈圆角方形。清除按钮覆盖 ghost 的 hover/active 背景，避免 44px 点击区域额外着色；实际浏览器三态均为 24×24 圆底、透明外层，临时伪状态已恢复。

抽屉右上关闭图标改为搜索图标，移除抽屉内搜索框。抽屉仍可通过遮罩或 Escape 关闭。点击搜索图标进入独立全屏搜索页，自动聚焦底部胶囊输入框；空输入显示居中的搜索提示。输入变化直接匹配标题与消息正文，无需点击提交；不显示假加载骨架。

结果包含聊天图标、标题和关键词附近的正文片段，关键词加粗，同一聊天只出现一次。没有匹配时提示更换关键词。清空按钮保留输入焦点；右侧关闭按钮和 Escape 返回抽屉，点击结果进入对应普通聊天。原聊天草稿、模型和正文滚动容器保留，搜索不修改聊天内容。

本轮只搜索内存中的普通聊天，包括原有、刚创建或导入的聊天；不搜索未发送草稿。没有连接 Remote 搜索服务，不增加数据权限或读取电脑目录。

## 分类条件

| 分类 | 当前依据与缺口 |
| --- | --- |
| 普通聊天 | 预览已有标题/messages，真实历史已有 title/turns，可建立标题与正文搜索；当前页面使用预览数据 |
| Remote 聊天/项目 | Remote 预览已有任务与 workspace 归属，可按工作区分组；真实统一项目搜索需要另外接入电脑目录与搜索接口 |
| 图片/文档 | 普通历史尚无可搜索的附件记录；需要文件标识、名称、类型、所属聊天等元数据，正文或图片内容搜索还需内容索引 |

真实依据：[普通聊天历史](../../../src/ordinary-history.mjs)、[Remote 预览](./RemotePreview.jsx)、[当前协议](../../../../backend/packages/protocol/src/index.ts)。当前协议仅开放会话列表/分页/跟随/控制/发送/停止，不能将内存工作区归属当作项目搜索服务已实现。

因此本轮不添加冗余的“全部/聊天”或空置的图片/文档/项目标签。分类是后续数据接入具备条件时的扩展点，没有从最终功能目标删除。

## 核对与限制

内置浏览器检查自动聚焦、不提交即匹配正文、无结果、清空保持焦点、结果打开、关闭/Escape 返回抽屉、草稿保持。375×667、360×640、375×400 无根页面溢出，底部输入可见；控制台无 error/warn。证据在 `artifacts/ordinary-preview-evidence/chat-search-*`。

`node scripts/ordinary-preview.mjs` 构建通过；`node --test tests/chat-search-preview.test.mjs` 两项测试通过，覆盖空查询、标题/正文、大小写、去重与长正文片段。浏览器自动聚焦已验证，实际 Android 自动弹出键盘尚未验证，短窗口不能替代软键盘测试。
