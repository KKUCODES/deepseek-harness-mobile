# DSHM 使用指南

DSHM 提供普通聊天和 Remote 两种入口。普通聊天使用手机自己的模型凭据和本地历史；Remote 连接电脑 DSH，手机和电脑共同参与同一个会话。

[返回项目首页](../README.md) · [开发与构建](./development.md)

## 安装与准备

当前是未发布的本地开发候选，Android 9 及以上可运行。获取本地候选与配套电脑插件时，先核对版本；本地验收使用官方 DSH `0.2.1-alpha.2` 和插件 `0.1.80-latest.0`，不能直接把任意新版 DSH 与旧手机包混用。

普通聊天只需要 DSHM 和自己的 DeepSeek Key。Remote 另需电脑上的官方 DSH、DSHM 插件及手机和电脑都能连接的中转地址。候选安装与版本核对见[配套安装说明](https://github.com/KKUCODES/dshm-plugin/blob/main/compatibility/latest-upstream/official-installation.md)；从源码构建见[开发指南](./development.md)。

## 普通聊天

1. 打开 App，点击「配置 DeepSeek Key」，在原生窗口中填写并保存。之后可在「设置 → 普通聊天」修改。
2. 在输入框选择模型和思考选项，输入消息后发送。生成期间可以停止。
3. 从侧边栏打开历史聊天，也可以搜索、改名或从已有回复创建分支。

普通聊天直连 DeepSeek，模型调用使用你的 API 额度。Key 保存在原生层，不放进聊天正文，也不会传给 Remote。

附件从手机系统选择；图片理解取决于所选模型。普通聊天不执行电脑上的 Agent 任务。已接入的输入插件可提供提示词等扩展，具体范围见[普通聊天说明](./integration/ordinary-current.md)。

### 历史与备份

聊天记录和草稿保存在手机。在「设置 → 本地数据」导出或导入备份；备份不包含模型凭据。卸载 App 或清除应用数据前，请先备份需要保留的聊天。

普通聊天历史与电脑 Remote 历史分别管理，切换入口不会把手机的 Key 或聊天混入电脑会话。

## 连接电脑

### 选择中转服务

**推荐自行搭建中转服务**，便于管理服务、数据与访问策略，搭建方式见[后端说明](https://github.com/KKUCODES/dshm-relay)。

暂时不想搭建时，可使用项目维护者提供的[公共中转服务](http://118.31.20.47:18787)。电脑插件的“服务地址”填写 `http://118.31.20.47:18787`，注册并开启连接，再生成链接给手机配对。公共服务为开放注册，不需要注册密钥，手机仍必须由电脑核对指纹后批准。

当前公共服务使用 HTTP，传输未加密；涉及敏感内容时建议自建并启用 HTTPS。它只用于 Remote，普通聊天仍由手机直连 DeepSeek。

电脑已注册其他中转时，在插件页“修改服务地址”选择“更换后端，重新注册和配对”，然后给手机使用新配对链接。完整步骤见[插件使用指南](https://github.com/KKUCODES/dshm-plugin/blob/main/docs/usage.md#5-修改服务地址)。

### 在电脑准备连接

1. 正常启动官方 DSH，安装配套 DSHM 插件；如果安装提示下次启动加载，重新启动 DSH。
2. 在插件页填写中转服务根地址和电脑名称，注册这台电脑，再开启远程连接。
3. 连接成功后，生成一次性配对链接。

中转的「开放使用」模式无需电脑首次注册密钥，「个人使用」模式需要。两种模式都要求电脑批准手机。注册密钥与手机普通聊天的 DeepSeek Key 是不同的凭据。

### 在手机配对

1. 从侧边栏进入「Remote」，粘贴完整配对链接，点击「继续配对」。
2. 在电脑插件页核对手机的公钥指纹并批准。
3. 手机点击「我已在电脑批准」，进入工作区和会话列表。

链接五分钟内有效，领取一次即失效。App 链接与系统分享入口也可进入配对确认；已有二维码时可扫描或从图片识别。当前电脑插件页提供配对链接，未提供二维码展示按钮。

### 继续工作

打开进行中或历史会话，或在已有工作区创建新会话。手机发送的消息进入同一份电脑会话，当前模型实时同步，手机切换会影响电脑后续回复。

DSH 需要提问、审批或计划确认时，可以在聊天中处理；也可以查看执行过程、命令结果、文件及改动预览。支持的局部插件界面沿用外层缩放规则，用户可以切换自适应设置。

管理电脑插件、工作区和设置需要电脑单独授予管理权限。已有工作区可改名、排序和移除注册；手机不创建新的电脑工作区。内容搜索需要电脑开启相应索引，未开启时仍可搜索标题。

## 文件、通知与断线

| 情况 | 处理方式 |
| --- | --- |
| 查看文件 | 从聊天或工具记录进入预览；文本、图片、PDF、隔离 HTML 和 Office 的支持范围见[文件说明](./integration/files-delivery-current.md)。 |
| 下载或分享 | 重新读取电脑最新完整原件，由 Android 选择保存位置或接收 App；接收 App 已取得的文件无法撤回。 |
| 连接中断 | 保留已加载内容和草稿，恢复后重新核对电脑状态。结果未确认的发送或审批不会自动重发。 |
| App 进程结束 | 不再接收通知，重新打开后尝试重连；电脑上已经开始的任务仍由 DSH 管理。 |
| 电脑或 DSH 退出 | 无法继续远程操作；重新连接不保证中断任务自动续跑。 |
| 撤销设备授权 | Remote 断开，该设备无法继续访问电脑；普通聊天仍独立可用。 |

文件格式、大小、转换依赖和异常范围以[当前兼容结论](https://github.com/KKUCODES/dshm-plugin/blob/main/compatibility/latest-upstream/official-support.md)及对应专项为准。手机不提供电脑命令输入，也不转发电脑 localhost 网站。

## 连接问题

- 中转地址需要手机和电脑都能访问。物理手机上的 `127.0.0.1` 指向手机自身；模拟器验收使用的 ADB 映射不等于公网部署。
- HTTP 和 HTTPS 都可使用。HTTP 连接未加密，界面会提示；建议使用 HTTPS。
- 配对等待批准时，先在电脑核对并批准；链接过期后重新生成。
- 升级 DSH 前核对手机与插件兼容版本。插件安装后未加载时，按提示正常重启 DSH。
- 可在「设置 → 问题诊断」或「Remote → 电脑连接 → 问题诊断」查看版本与连接状态；诊断用途见[问题诊断说明](./integration/diagnostics-current.md)。
