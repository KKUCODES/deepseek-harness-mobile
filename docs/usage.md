# DSHM 使用指南

DSHM 提供普通聊天和 Remote 两种入口。普通聊天使用手机自己的模型凭据和本地历史；Remote 连接电脑 DSH，手机和电脑共同参与同一个会话。

[返回项目首页](../README.md) · [开发与构建](./development.md)

## 安装与准备

从 [GitHub Releases](https://github.com/KKUCODES/deepseek-harness-mobile/releases) 下载已签名 `.apk`，Android 9 及以上可安装。当前preview.13保留普通聊天自定义供应商与模型；Remote配套插件 `0.1.87-latest.0`，核心支持范围为官方 DSH `0.2.0-rc.2` / `0.2.1-alpha.2` / `0.2.1-rc.2`。不要直接混用任意新版 DSH 与旧手机包，实际验证范围及安装说明见[安装包指南](./releases.md)。

普通聊天只需要 DSHM 和所选模型服务的 API Key，默认可使用 DeepSeek。Remote 另需电脑上的官方 DSH、DSHM 插件及手机和电脑都能连接的中转地址。候选安装与版本核对见[配套安装说明](https://github.com/KKUCODES/dshm-plugin/blob/main/compatibility/latest-upstream/official-installation.md)；从源码构建见[开发指南](./development.md)。

## 普通聊天

1. 打开 App，点击「配置 DeepSeek Key」，在原生窗口中填写并保存。之后可在「设置 → 普通聊天 → 管理供应商与模型」管理 Key 或添加其他服务。
2. 在输入框选择模型和思考选项，输入消息后发送。生成期间可以停止。
3. 从侧边栏打开历史聊天，也可以搜索、改名或从已有回复创建分支。

普通聊天直连所选供应商，模型调用使用你的 API 额度。Key 保存在原生层，不放进聊天正文，也不会传给 Remote。

附件从手机系统选择；图片理解取决于所选模型。普通聊天不执行电脑上的 Agent 任务。已接入的输入插件可提供提示词等扩展，具体范围见[普通聊天说明](./integration/ordinary-current.md)。

### 历史与备份

聊天记录和草稿保存在手机。在「设置 → 本地数据」导出或导入备份；备份不包含模型凭据。卸载 App 或清除应用数据前，请先备份需要保留的聊天。

普通聊天历史与电脑 Remote 历史分别管理，切换入口不会把手机的 Key 或聊天混入电脑会话。

### 自定义供应商与模型

从 `0.1.0-preview.5` 起支持；旧版用户先覆盖安装新版，再按下面配置：

1. 进入「设置 → 普通聊天 → 管理供应商与模型」，点击「添加供应商」。所有自定义服务使用同一入口。
2. 填写供应商名称、HTTPS API 基础地址和模型 ID，例如 `https://example.com/v1`。不要填写完整的 `/chat/completions` 路径，也不要把 Key 放进地址。
3. 保存后打开该供应商，在「配置 Key」原生密码窗口中填写这个服务自己的 Key。
4. 在输入框的模型菜单选择供应商与模型。「设置 → 普通聊天 → 默认模型」只影响新聊天，已有聊天保持原来的选择。

服务需兼容 OpenAI Chat Completions 的文本与 SSE 流格式。图片、思考字段、输出上限字段和随机性参数按服务文档设置。默认省略这些扩展参数；始终思考的模型不要使用会发送关闭思考参数的设置。普通聊天不提供工具执行或 Responses、Anthropic 等其他协议。

内置 DeepSeek 沿用原 Key 和聊天。使用 DeepSeek 中转站时添加独立供应商和对应 Key；更换地址前先在「管理 Key」移除该供应商旧 Key。删除供应商会移除配置和 Key，保留聊天、回复与草稿，相关聊天需要重新选择模型才能继续。

新版备份格式为 v2，仍可导入旧 v1；旧 App 不支持导入新版备份。备份只包含聊天及供应商/模型标识，不包含服务地址、配置或 Key。在其他设备恢复自定义聊天后，先配置服务并手动重新选择模型。详细规则见[模型服务说明](./integration/ordinary-providers-current.md)。

## 连接电脑

### 选择中转服务

**推荐自行搭建中转服务**，便于管理服务、数据与访问策略，搭建方式见[后端说明](https://github.com/KKUCODES/dshm-relay)。

暂时不想搭建时，可使用项目维护者提供的[公共中转服务](http://118.31.20.47:18787)。电脑插件的“服务地址”填写 `http://118.31.20.47:18787`，注册并开启连接，再生成链接给手机配对。公共服务为开放注册，不需要注册密钥，手机仍必须由电脑核对指纹后批准。

当前公共服务使用 HTTP，传输未加密；涉及敏感内容时建议自建并启用 HTTPS。它只用于 Remote，普通聊天仍由手机直连 DeepSeek。

电脑已注册其他中转时，在插件页“修改服务地址”选择“更换后端，重新注册和配对”，然后给手机使用新配对链接。完整步骤见[插件使用指南](https://github.com/KKUCODES/dshm-plugin/blob/main/docs/usage.md#5-修改服务地址)。

### 在电脑准备连接

1. 正常启动官方 DSH，安装配套 DSHM 插件；如果安装提示下次启动加载，重新启动 DSH。
2. 在插件页填写中转服务根地址和电脑名称，注册这台电脑，再开启远程连接。
3. 连接成功后，生成一次性配对链接。

中转的「开放使用」模式无需电脑首次注册密钥，「个人使用」模式需要。两种模式都要求电脑批准手机。注册密钥与手机普通聊天的 DeepSeek Key 是不同的凭据。

### 在手机配对

1. 从侧边栏进入「Remote」，粘贴完整配对链接，点击「继续配对」。
2. 在电脑插件页核对手机的公钥指纹并批准。
3. 手机点击「我已在电脑批准」，进入工作区和会话列表。

链接五分钟内有效，领取一次即失效。App 链接与系统分享入口也可进入配对确认；已有二维码时可扫描或从图片识别。当前电脑插件页提供配对链接，未提供二维码展示按钮。

### 继续工作

打开进行中或历史会话，或在已有工作区创建新会话。手机发送的消息进入同一份电脑会话，当前模型实时同步，手机切换会影响电脑后续回复。

preview.13支持向上阅读到顶部附近自动加载一批更早记录，保持当前阅读位置；加载失败时可点击「加载更早的消息」重试。主聊天与旁栏共用此行为，仍可加载较新记录或返回最新。preview.12及更早版需点击按钮加载历史。

DSH 需要提问、审批或计划确认时，可以在聊天中处理；也可以查看执行过程、命令结果、文件及改动预览。支持的局部插件界面沿用外层缩放规则，用户可以切换自适应设置。

管理电脑插件、工作区和设置需要电脑单独授予管理权限。已有工作区可改名、排序和移除注册；手机不创建新的电脑工作区。内容搜索需要电脑开启相应索引，未开启时仍可搜索标题。

## 文件、通知与断线

| 情况 | 处理方式 |
| --- | --- |
| 查看文件 | 从聊天或工具记录进入预览；文本、图片、PDF、隔离 HTML 和 Office 的支持范围见[文件说明](./integration/files-delivery-current.md)。 |
| 下载或分享 | 重新读取电脑最新完整原件，由 Android 选择保存位置或接收 App；接收 App 已取得的文件无法撤回。 |
| 连接中断 | 保留已加载内容和草稿，恢复后重新核对电脑状态。结果未确认的发送或审批不会自动重发。 |
| App 进程结束 | 不再接收通知，重新打开后尝试重连；电脑上已经开始的任务仍由 DSH 管理。 |
| 电脑或 DSH 退出 | 无法继续远程操作；重新连接不保证中断任务自动续跑。 |
| 撤销设备授权 | Remote 断开，该设备无法继续访问电脑；普通聊天仍独立可用。 |

文件格式、大小、转换依赖和异常范围以[当前兼容结论](https://github.com/KKUCODES/dshm-plugin/blob/main/compatibility/latest-upstream/official-support.md)及对应专项为准。手机不提供电脑命令输入，也不转发电脑 localhost 网站。

preview.12修复Remote正文与Markdown文件预览中的网页链接：HTTP/HTTPS交系统浏览器，返回后保留Remote；项目文件仍在原预览中打开。无法打开时显示原因。需要升级APK，不能仅更新旧版页面资源。详见[外链处理与验证范围](./integration/remote-links-diagnosis.md)。

长聊天可继续「加载更早的消息」「加载较新的消息」或「返回最新消息」，电脑原历史不删除。手机只保留当前窗口，长回复/思考和输出可逐段查看；翻页不停止电脑任务和待审批。单条显示出错可点「重新显示」，渲染进程退出时App尝试自动恢复。见[预算、恢复与验证限制](./integration/remote-history-window-current.md)。

## 连接问题

- 中转地址需要手机和电脑都能访问。物理手机上的 `127.0.0.1` 指向手机自身；模拟器验收使用的 ADB 映射不等于公网部署。
- HTTP 和 HTTPS 都可使用。HTTP 连接未加密，界面会提示；建议使用 HTTPS。
- 配对等待批准时，先在电脑核对并批准；链接过期后重新生成。
- 升级 DSH 前核对手机与插件兼容版本。插件安装后未加载时，按提示正常重启 DSH。
- 可在「设置 → 问题诊断」或「Remote → 电脑连接 → 问题诊断」查看版本与连接状态；诊断用途见[问题诊断说明](./integration/diagnostics-current.md)。

## App 更新

preview.11将APK与页面资源合并为统一更新卡片，主按钮依状态显示下载、安装或「重启并应用」，更新说明和技术信息可展开查看；[实现与验收范围](./integration/unified-updates-current.md)。

preview.10起支持[页面资源更新](./integration/web-resource-updates-current.md)。preview.11下载兼容资源后，点击「重启并应用」即可自动重新打开原模式；先保存各页面草稿，发送中或保存失败时保留当前页面并提示重试，无需去系统设置强行停止。失败可恢复上一可用版或APK内置页面，保留本地数据；涉及原生能力仍升级APK。本次不发布r2，尚无兼容新资源包时继续使用内置页面。

从preview.8开始支持App内更新。preview.7及更早的公开版没有更新入口，请先从[发行页](https://github.com/KKUCODES/deepseek-harness-mobile/releases)下载最新APK覆盖安装；之后可在「设置 → 软件更新」或「Remote → 连接选项 → 软件更新」手动检查，启动时每天也会检查一次。

发现新版后查看更新内容及配套插件要求，点击下载；下载完成并验证后，点击「安装更新」。首次需在Android设置允许此来源，返回后再次点击安装，再由系统确认覆盖安装。安装会保留原应用数据，请勿先卸载。系统扫描或安装取消后，可返回App重新操作；网络失败时可重试或前往发行页下载。详情见[更新说明与验证边界](./integration/app-updates-current.md)。
