## 本次更新

- **触顶自动加载历史**：Remote 主聊天和旁栏中，向上阅读到顶部附近即可加载一批更早记录，不必反复点击按钮。
- **阅读位置保持**：继续使用有界数据窗口和可见区域渲染，加载前后保留正在阅读的位置；实时同步、审批、草稿和输入插件状态保持。
- **避免反复请求**：同一时间只加载一批，一次触摸不会连读多批。首次进入、程序定位和重连不自动拉取全部历史；失败可点击按钮重试，读完后停止加载并提示。

配套[电脑插件 0.1.87-latest.0](https://github.com/KKUCODES/dshm-plugin/releases/tag/v0.1.87-latest.0)保持不变，无需额外升级插件或中转；缺少此前大响应分块的自建中转仍需包含提交 `94183d0`。不修改 DSH 本体，不包含独立插件适配分支。

只发布 APK，不投放 r2 页面资源包；公共资源通道 r1 保持不变。本次更新保留 preview.12 的长聊天与外链修复。

## 验证范围

567 项 Node 测试、两版 SDK 的真实列表入口连续 24 批自动加载及独立 Android WebView 回归通过；覆盖触摸、键盘、阅读位置、单批在途、失败重试、离线恢复、在途切换、读完停止请求及旁栏加载。数据是隔离合成协议，尚未取得反馈用户的原始长聊天，不代表完整真机或真实公网配对验收。

既有窗口预算允许完整保留单条大事件和未结算的流式步骤，并非整个 WebView 的硬内存上限；任意第三方插件仅存于 React Hook 内的私有状态仍取决于插件实现。

## What's changed

- **Automatic history loading**: scroll upward near the top of a Remote conversation to load one earlier batch, in both the main chat and sidebar.
- **Keep your place**: reading anchors, bounded data windows and viewport rendering remain in use. Live synchronization, approvals, drafts and input-plugin state are preserved.
- **Avoid repeated requests**: only one batch is in flight, and one touch gesture cannot fetch several batches. Initial entry, programmatic positioning and reconnecting do not fetch all history. Manual retry and an end-of-history indicator remain available.

Download **DSHM-0.1.0-preview.13.apk** for Android 9 or newer. Version code 16 uses the existing application ID and signing certificate and can replace preview.1–preview.12 while retaining chats, keys and pairing. **Do not uninstall first.** In-app updates are available from preview.8.

The companion desktop plugin remains **0.1.87-latest.0**. No additional plugin or relay upgrade is required; self-hosted relays missing the earlier large-response fix still need commit `94183d0`. No DSH core changes or code from the separate plugin-adaptation branch.

**APK only; r2 is not published.** Existing r1 resources and preview.12's history and external-link fixes remain.

567 Node tests, 24-batch regressions with two SDK versions and isolated Android WebView checks passed, including touch/keyboard input, scroll anchors, request serialization, retries, reconnecting, switching conversations and sidebar history. Synthetic protocol replay does not establish complete physical-device or paired public-network coverage; the user's original long conversation was unavailable. Atomic large records and active stream steps can exceed the history target, and arbitrary plugin-private React Hook state cannot be generically serialized.
