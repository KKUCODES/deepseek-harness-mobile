DSHM Android 开发预览版 / Android development preview

### 本次更新

- 缓存未变化的 Remote 插件资源。重新打开时先向电脑校验，有变化才重新下载；资源损坏会重新读取。
- 工作区与聊天首次建立基线，后续尽量差量同步；电脑变化继续实时传到手机。缓存按设备绑定隔离，写操作与审批不会自动重放。
- 普通聊天和 Remote 共用 Logo 启动封面，首屏可显示后平滑淡出，修复白屏和“正在打开…”的裸文字闪现。
- Remote 不等待电脑联网才撤下 Logo，离线时仍能看到可操作的连接页；加载失败可重试，兼容系统关闭动画。

### 下载与更新

下载下方 **DSHM-0.1.0-preview.4.apk**，Android 9 及以上可安装。沿用原应用身份和签名，可直接覆盖 preview.1 / preview.2 / preview.3，保留本地记录；请勿先卸载旧版。

Remote 完整缓存优化需配套更新[电脑插件 0.1.85-latest.0](https://github.com/KKUCODES/dshm-plugin/releases/tag/v0.1.85-latest.0)。继续支持官方 DSH **0.2.0-rc.2 / 0.2.1-alpha.2**，电脑需保持运行；现有中转服务无需升级，不修改 DSH 本体。普通聊天仍使用手机配置的 DeepSeek Key。

已完成浏览器与 MuMu Android 12L 的启动、重试、缓存恢复、实时更新及离线/重连验证。真机、公网及任意第三方插件仍有待扩大验证；本轮 rc.2 缓存路径做构建核对，不将 alpha.2 实测外推为 rc.2 运行验收。附带 SHA-256、签名报告和兼容元数据。

### What's changed

- Reuse unchanged Remote plugin assets after desktop revalidation; refetch changed or corrupt resources.
- Incremental workspace and chat synchronization, with live desktop updates and binding-isolated caches. Writes and approvals are never replayed automatically.
- One shared Logo startup cover for ordinary chat and Remote, fading into a render-ready page without bare loading text.
- An actionable connection screen while the computer is offline, startup retry and reduced-motion support.

Download the APK below for Android 9 or newer. Install over preview.1 / preview.2 / preview.3 to preserve local data; the application identity and signing certificate are unchanged. Update the desktop plugin to **0.1.85-latest.0** for the full caching improvements. Official DSH 0.2.0-rc.2 / 0.2.1-alpha.2 remain supported; the existing relay needs no deployment and no DSH core patches are required.

Browser and MuMu checks do not replace physical-device or public-network validation. The new cache runtime checks used official alpha.2; rc.2 received build checks in this iteration. Checksums, signing and compatibility reports are included.
