# DSHM 0.1.0-preview.20

- 修复 Remote 从会话过程点击文件名后预览空白的问题。文件预览继续使用 DSH 官方组件。
- 预览组件异常时会显示提示，仍可返回聊天、下载或分享完整文件。
- 配套官方 DSH `0.2.2-rc.3` 与桌面插件 `0.1.88-latest.0`。APK 使用原签名，可覆盖安装。

## English

- Fixed blank Remote file previews when opening a file from the conversation process. File previews continue to use the official DSH component.
- If the preview fails to render, the panel displays a message and keeps the chat, download, and share actions available.
- Compatible with official DSH `0.2.2-rc.3` and desktop plugin `0.1.88-latest.0`. The APK supports in-place upgrades with the existing signing certificate.
