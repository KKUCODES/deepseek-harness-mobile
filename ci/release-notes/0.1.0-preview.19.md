# DSHM 0.1.0-preview.19

- 修复部分 Android 手机在 Remote 中选完图片后没有添加附件的问题。待发送图片使用 DSH 官方缩略图组件，支持横向滚动和原图预览。
- Remote 工作区内直接新建会话，总览页可选择工作区。默认首页和新版首页插件共用此入口。
- 新增可开关的实时诊断日志，覆盖普通聊天、Remote、启动、插件和更新。近期日志重启后可查看，错误详情可复制脱敏调用栈。
- Remote 已在官方 DSH `0.2.2-rc.3` 验收，配套桌面插件为 `0.1.88-latest.0`。APK 使用原签名，可覆盖安装。

## English

- Fixed a Remote issue where selected images were silently dropped on some Android devices. Image drafts use the official DSH thumbnail rail with horizontal scrolling and an original-image preview.
- Create a chat directly from a Remote workspace. The Remote overview offers a workspace picker. Both home layouts share this behavior.
- Added live diagnostics with a recording switch for API chat, Remote, startup, plugins, and updates. Recent logs survive restarts, and error details include copyable, redacted stack traces.
- Remote was validated with official DSH `0.2.2-rc.3` and desktop plugin `0.1.88-latest.0`. The APK supports in-place upgrades with the existing signing certificate.
