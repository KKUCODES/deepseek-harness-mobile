# DSHM 0.1.0-preview.16

## 中文

- Remote 回到前台时检查电脑连接。连接失效时立即尝试恢复，保留已显示的聊天内容。
- 从列表重进最近会话时先显示缓存，再同步电脑上的消息。继续上次的阅读位置，或跟随最新消息。
- 修复 Lexical 重复打包导致的「草稿引用无法恢复」提示。

使用原签名。请在现有 App 上覆盖安装，以保留聊天、草稿和配对信息。配套电脑插件为 `0.1.87-latest.0`。

[直接下载 APK](https://github.com/KKUCODES/deepseek-harness-mobile/releases/download/v0.1.0-preview.16/DSHM-0.1.0-preview.16.apk)

## English

- Remote checks the desktop connection when the app returns to the foreground. If the connection has dropped, the app tries to reconnect immediately and keeps the current chat visible.
- Reopening a recent conversation shows cached messages while syncing with the desktop. The app restores your reading position or follows the latest messages.
- Fix a duplicate Lexical runtime that could trigger a draft reference recovery error.

Install over the existing app to keep chats, drafts, and pairing. This APK uses the existing signing certificate. The companion desktop plugin is `0.1.87-latest.0`.
