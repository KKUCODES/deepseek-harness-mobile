DSHM Android 开发预览 / Android development preview

### 本次更新

- 修复较长聊天因「响应过大」无法打开的问题。首次快照、历史分页和实时大事件共用分块传输，手机完整校验后显示。
- 加入四块确认窗口、大小/并发上限、超时及取消清理；断线丢弃未完成数据，重新连接重新读取，不自动重发写操作。
- 保留原有 DSH 兼容范围、普通聊天供应商、Key、聊天记录及签名身份。不包含独立插件适配分支，不修改 DSH 本体。

### 下载与配套升级

下载 **DSHM-0.1.0-preview.7.apk**，Android 9及以上可覆盖 preview.1–preview.6安装；不要先卸载旧版。

请同时更新[电脑插件0.1.87-latest.0](https://github.com/KKUCODES/dshm-plugin/releases/tag/v0.1.87-latest.0)并重启DSH，**自建中转也需升级到包含共享协议提交 `94183d0` 的版本**。任一旧端会保持旧小响应通信，仍受原2MiB上限限制。每条新逻辑响应最多32MiB，这是传输上限，不代表任意大段正文的渲染性能保证。

532项手机测试、261项插件测试及适用后端回归114项通过。官方DSH 0.2.1-rc.2＋Android12模拟设备的60回合合成工具输出聊天，已验证约2.55MB首次快照、2.52MB历史页和重连后大快照，物理帧最大87,525字节。实时大事件通过真实中转/Relay/手机客户端的合成联调验证；无真实模型调用。本轮不声明完整真机、Electron或所有第三方插件验收。

### What's changed

- Fix oversized Remote responses across initial snapshots, older-history pages and large live events with acknowledged, verified chunks.
- Bound transfer size, concurrency and queues; clean up on cancellation, timeout and disconnect. Reconnect reads fresh state without replaying writes.
- Preserve existing DSH compatibility, direct-chat providers, Keys, history, app identity and signing certificate. No DSH core changes or code from the separate plugin-adaptation branch.

Install **DSHM-0.1.0-preview.7.apk** over preview.1–preview.6 without uninstalling. Update the desktop plugin to **0.1.87-latest.0**, restart DSH, and upgrade self-hosted relays to include commit **94183d0**. Older peers retain the original small-response protocol and 2MiB limit. New logical responses are capped at32MiB; rendering performance for arbitrary large text is not guaranteed.

532 mobile,261 plugin and114 applicable relay tests passed. An unmodified official DSH rc.2 and an Android12 emulator passed synthetic60-turn large-chat snapshot, pagination and reconnect checks. Large live events were checked through the real relay/plugin/client transport with synthetic data. No model calls or full physical-device/Electron/third-party-plugin validation.
