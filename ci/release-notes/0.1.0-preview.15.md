# DSHM 0.1.0-preview.15

## 中文

- 以 preview.11 的聊天体验重新迭代，恢复手动加载和连续历史阅读，移除较新页操作栏、自动触顶加载与正文分段按钮。
- 保留长聊天可见区域渲染、前插位置保护与失败重试；原会话和插件公开接口保持官方行为。
- 保留 Remote 聊天及 Markdown 文件预览外链，由系统浏览器打开。
- 保留新版 Remote 页面、独立首页插件的安装管理和默认首页回退，以及脱敏连接错误栈。
- 使用 DSH 原滚动跟随逻辑和向下箭头按钮，阅读旧消息时可一键回到最新位置。
- 普通聊天、Remote 和 Markdown 预览共用代码块组件，保留原换行开关与复制操作，随包提供等宽字体；宽表格支持触摸横向滚动。
- 修复图片消息导致会话空白的问题，复用 DSH 图片画廊并隔离局部加载错误；修复部分轮次的思考过程无法展开，兼容旧版 DSH。
- 待连接页也通过公开插件接口加载；停用、卸载或加载失败时，待连接页与项目列表均回退默认界面。预装「Remote 新版首页」更新为 0.4.0。
- 沿用原签名；请覆盖安装以保留聊天、Key、配对和插件记录。

[直接下载 APK](https://github.com/KKUCODES/deepseek-harness-mobile/releases/download/v0.1.0-preview.15/DSHM-0.1.0-preview.15.apk)。配套电脑插件：`0.1.87-latest.0`；本版不要求额外升级插件或中转，不发布 r2 资源包。

已安装的首页插件不会被 App 升级强制覆盖或重新启用，已卸载的插件不会复活。需要新版待连接界面时，请在插件页卸载旧版后，从预装插件恢复安装 0.4.0；配对与聊天数据保留。历史数据仍随阅读增长，不承诺所有规模下固定内存占用。两版 SDK、MuMu 与实际电脑连接的验证范围见[验证说明](https://github.com/KKUCODES/deepseek-harness-mobile/blob/v0.1.0-preview.15/docs/integration/preview15-rebuild-current.md)。

## English

- Rebuild on preview.11's chat experience: manually load older messages and browse already loaded history continuously. Remove newer-page controls, automatic top loading and body pagination buttons.
- Keep viewport rendering, prepend position protection and retry without replacing official Session or plugin interfaces.
- Keep system-browser links from Remote chat and Markdown previews.
- Keep redesigned Remote pages, independent home-plugin management, default-home fallback and redacted connection traces.
- Use DSH's original scroll-follow controller and down-arrow button to return to the latest message.
- Share the code-block renderer across direct chat, Remote and Markdown previews, including wrapping and copying, with an offline monospace font. Wide tables support horizontal touch scrolling.
- Fix image messages blanking the conversation by reusing DSH's image gallery with local error isolation. Fix reasoning sections that could not expand, while retaining older DSH support.
- Extend the public plugin interface to the connection page. Disabling, removing or failing to load a plugin restores both default views. The preinstalled Remote home plugin is now 0.4.0.
- Install over the existing app to retain chats, keys, pairing and plugin records. The signing identity is unchanged.

[Download APK directly](https://github.com/KKUCODES/deepseek-harness-mobile/releases/download/v0.1.0-preview.15/DSHM-0.1.0-preview.15.apk). Companion desktop plugin: `0.1.87-latest.0`; no additional plugin or relay upgrade is required. This release does not publish the r2 web resource package.

App upgrades retain installed plugin versions, disabled preferences and uninstall records. To use the new connection view, remove the older home plugin from the plugin page, then restore the preinstalled 0.4.0 package; pairing and chats are retained. Loaded SDK data can still grow; this is not a fixed memory limit. See the [validation scope (Chinese)](https://github.com/KKUCODES/deepseek-harness-mobile/blob/v0.1.0-preview.15/docs/integration/preview15-rebuild-current.md).
