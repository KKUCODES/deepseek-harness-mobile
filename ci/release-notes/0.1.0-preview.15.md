# DSHM 0.1.0-preview.15

发行说明草稿：本地候选，尚未发布。

## 中文

- 以 preview.11 的聊天体验重新迭代，恢复手动加载和连续历史阅读，移除较新页操作栏、自动触顶加载与正文分段按钮。
- 保留长聊天可见区域渲染、前插位置保护与失败重试；原会话和插件公开接口保持官方行为。
- 保留 Remote 聊天及 Markdown 文件预览外链，由系统浏览器打开。
- 保留新版 Remote 页面、独立首页插件的安装管理和默认首页回退，以及脱敏连接错误栈。
- 沿用原签名；请覆盖安装以保留聊天、Key、配对和插件记录。

配套电脑插件：`0.1.87-latest.0`；本版不要求额外升级插件或中转。历史数据仍随阅读增长，不承诺所有规模下固定内存占用。验证范围见 `docs/integration/preview15-rebuild-current.md`。

## English

- Rebuild on preview.11's chat experience: manually load older messages and browse already loaded history continuously. Remove newer-page controls, automatic top loading and body pagination buttons.
- Keep viewport rendering, prepend position protection and retry without replacing official Session or plugin interfaces.
- Keep system-browser links from Remote chat and Markdown previews.
- Keep redesigned Remote pages, independent home-plugin management, default-home fallback and redacted connection traces.
- Install over the existing app to retain chats, keys, pairing and plugin records. The signing identity is unchanged.

Companion desktop plugin: `0.1.87-latest.0`; no additional plugin or relay upgrade is required. Loaded SDK data can still grow; this is not a fixed memory limit.
