## 本次更新

- 修复 **Remote 项目聊天中返回手势不生效**：从会话列表打开聊天，读取完成后可用系统返回手势或返回键退出，不再只能点击左上角箭头。
- 保留原有返回顺序：先关闭菜单、弹窗和插件面板，再返回聊天列表与项目列表；聊天草稿保持。
- 增加从真实列表按钮进入会话的回归，覆盖读取忙碌期、读取完成、连续进入和返回，以及插件页面的返回优先级。

## 安装

下载 **[DSHM-0.1.0-preview.9.apk](https://github.com/KKUCODES/deepseek-harness-mobile/releases/download/v0.1.0-preview.9/DSHM-0.1.0-preview.9.apk)**，Android 9 及以上可直接安装，或覆盖 preview.1–preview.8。保持原包名和签名，**请勿先卸载旧版**。

preview.8 用户也可在「设置 → 软件更新」或「Remote → 连接选项 → 软件更新」检查后下载。preview.7 及更早版本请手动下载覆盖安装。

配套 [电脑插件 0.1.87-latest.0](https://github.com/KKUCODES/dshm-plugin/releases/tag/v0.1.87-latest.0) 保持不变。本版无需额外升级插件或中转；此前尚未完成长聊天分块升级的自建中转仍需包含协议提交 `94183d0`。不修改 DSH 本体，不包含独立插件适配分支。

rc.2 与 alpha.2 组件回放专项、540 项本地测试及手机页面构建通过；Android 16 原生返回键、边缘手势及弹窗分层结合当前组件回放验证通过，不代表真实配对或物理手机完整验收。额外的旧全屏动效专项存在修复前同样可复现的偶发失败，未混入本次修复。

## What's changed

- Fix **system back gestures in Remote project chats**. After opening a chat from its list and finishing loading, use the system gesture or back button to return; the top-left arrow is no longer the only working route.
- Preserve the existing back order: menus, dialogs and plugin panels close before navigating out of the chat and project. Drafts are retained.
- Add regression coverage through actual session-list buttons, including loading, repeated navigation and plugin surface priority.

Download **DSHM-0.1.0-preview.9.apk** for Android 9 or newer. Install over preview.1–preview.8 without uninstalling. preview.8 users can also use the in-app updater; earlier versions need a manual download.

The companion desktop plugin remains **0.1.87-latest.0**. No additional plugin or relay upgrade is required; self-hosted relays missing the earlier large-response fix still need protocol commit `94183d0`. No DSH core changes or code from the separate plugin-adaptation branch.

rc.2 and alpha.2 component replay checks, 540 local tests and the mobile web build passed. Android 16 native back keys, edge gestures and layered dialogs passed with the current component replay; this does not establish full paired-session or physical-device coverage. An additional legacy fullscreen-motion check has an intermittent failure reproducible before this fix and is outside this change.
