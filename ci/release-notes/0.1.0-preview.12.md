## 本次更新

- **长聊天更稳**：限制手机累计持有的历史窗口，仅渲染可见区域；连续加载历史不再持续堆积全部记录和页面节点。电脑历史仍完整保留，可向前、向后查阅或返回最新消息。
- **长内容分段查看**：超长回复、思考和后台输出按段显示，加载前后保留阅读位置；实时同步、审批、草稿和会话级插件状态继续使用。
- **显示异常可恢复**：出错记录提供重试；WebView渲染进程退出后自动重建页面，连续失败保留手动恢复入口，不自动重发消息或审批。
- **网页链接可点击**：Remote聊天和Markdown文件预览中的HTTP(S)网页交给系统浏览器打开；项目文件继续在App内预览，保留原来源和协议限制。

## 验证边界

563项Node测试、rc.2/alpha.2实际会话入口连续24页回放、实时追加/双向查阅/失败重试/重连基线、审批、插件输入状态、长内容及文件链接回归通过；独立Android真实WebView和渲染进程退出后的重建、同源存储保持通过。页面与历史为合成协议回放，用户反馈的原始持续白屏未直接复现，真实配对后的崩溃阅读位置恢复仍未实测。

数据预算允许完整保留单条大事件和未结算的流式步骤，不是整个WebView的硬内存上限。任意第三方插件仅存React Hook内的私有状态仍取决于插件实现。

## What's changed

- **More stable long conversations**: bounded history windows and viewport rendering prevent every loaded page from accumulating in memory and the DOM. Computer history is retained, with older/newer browsing and a return-to-latest action.
- **Paged long content**: large replies, reasoning and recorded background output are displayed in parts. Keep reading anchors, live synchronization, approvals, drafts and session-level plugin state.
- **Display recovery**: retry failed records and rebuild the page after a WebView renderer exits. Automatic recovery is limited; manual recovery remains available. Messages and approval decisions are never automatically replayed.
- **Working web links**: HTTP(S) links in Remote chat and Markdown file previews open in the system browser. Project files keep their in-app previews and existing security restrictions.

Download **DSHM-0.1.0-preview.12.apk** for Android 9 or newer. Version code15 uses the existing application ID and signing certificate and can replace preview.1–preview.11 while retaining chats, keys and pairing. **Do not uninstall first.** In-app APK updates are available from preview.8.

The companion desktop plugin remains **0.1.87-latest.0**. No additional plugin or relay upgrade is required; self-hosted relays missing the earlier large-response fix still need commit`94183d0`. No DSH core changes or code from the separate plugin-adaptation branch.

**APK only; r2 is not published.** The existing public r1 resources remain unchanged. The new external-link and native recovery capabilities require this APK.

The originally reported persistent white screen was not directly reproduced, and restoring the reading position after a renderer crash with a real paired computer remains unverified.
