DSHM Android 开发预览版 / Android development preview

### 本次更新

- 普通聊天支持自定义供应商、HTTPS API 基础地址、独立 Key 和模型，采用 OpenAI Chat Completions 兼容格式。
- 统一从「设置 → 普通聊天 → 管理供应商与模型 → 添加供应商」配置。输入框可切换供应商与模型，默认模型只影响新聊天。
- 保留内置 DeepSeek 配置、原 Key、聊天记录和草稿。删除供应商保留聊天，继续发送前明确要求重新选择模型。
- 每个供应商的 Key 独立保存在原生加密存储中；更换地址前须移除该供应商旧 Key，不会将旧 Key 自动发往新站点。
- 新备份格式 v2 保留供应商与模型标识，仍可导入旧 v1。备份不含服务配置或 Key；旧 App 不能导入新版备份，跨设备恢复后需要重新配置服务并选择模型。

### 下载与更新

下载下方 **DSHM-0.1.0-preview.5.apk**，Android 9 及以上可直接安装。沿用原应用身份和签名，可覆盖 preview.1–preview.4，保留本地数据；请勿先卸载旧版。

普通聊天默认使用 DeepSeek，也可添加兼容服务并填写该服务自己的 Key。图片、思考和输出上限等能力按供应商文档选择；不支持 Responses、Anthropic 协议或普通聊天工具执行。

Remote 继续配套[电脑插件 0.1.85-latest.0](https://github.com/KKUCODES/dshm-plugin/releases/tag/v0.1.85-latest.0)，支持官方 DSH **0.2.0-rc.2 / 0.2.1-alpha.2**。本次无需升级插件或中转服务，电脑端 DSH 不变。

512 项自动回归及隔离 MuMu Android 12L 的配置、旧数据、重启与删除流程已通过；DeepSeek、GLM 官方接口已分别收到真实流式回复，同一聊天切换也通过。GLM 后续遇到限流，失败记录保留并停止继续调用。未据此宣称任意中转站、所有模型、真机或完整公网验收通过。附带 SHA-256、签名与兼容元数据。

### What's changed

- Custom direct-chat providers, HTTPS API base URLs, separate keys and models using the OpenAI Chat Completions compatible format.
- One generic Add provider form, per-chat model selection and a default model for new chats.
- Existing DeepSeek settings, encrypted credentials, chats and drafts are retained. Removing a provider keeps its chats and requires an explicit model selection before sending again.
- Separate native encrypted credentials per provider. Remove the old key before changing its API address.
- Backup v2 preserves provider/model identifiers and imports legacy v1 backups. Service settings and keys are excluded; older apps cannot import v2. Reconfigure the service and select a model when restoring on another device.

Download **DSHM-0.1.0-preview.5.apk** below for Android 9 or newer. Install over preview.1–preview.4 without uninstalling to retain local data; the application identity and signing certificate are unchanged.

Use each provider's own key and configure capabilities according to its documentation. Responses, Anthropic and direct-chat tool execution are not supported. Remote keeps desktop plugin **0.1.85-latest.0** and official DSH **0.2.0-rc.2 / 0.2.1-alpha.2** compatibility; no desktop plugin, relay or DSH core update is needed for this release.

512 automated tests and isolated MuMu configuration/data checks passed. Real DeepSeek and GLM streaming replies and provider switching were verified; a later GLM rate-limit failure is retained, with further calls stopped. These results do not establish compatibility with every provider, physical device or public-network setup.
