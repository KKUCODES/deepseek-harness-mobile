DSHM Android 开发预览 / Android development preview

### 本次更新

- 新增官方 DSH **0.2.1-rc.2** 的核心 Remote 连接支持，保留 **0.2.0-rc.2 / 0.2.1-alpha.2**。
- 版本校验改为有界兼容范围和实际能力检查；补齐平台模块、主题默认字段与原生通知兼容，修复启动期间的加载失败。
- App 固定官方 rc.2 SDK，保留原来的普通聊天、自定义供应商、DeepSeek 配置、聊天记录、缓存与启动过渡。

### 下载与更新

下载 **DSHM-0.1.0-preview.6.apk**，Android 9 及以上直接安装。沿用原应用身份和签名，可覆盖 preview.1–preview.5；请勿先卸载旧版。

连接 rc.2 请同时升级[电脑插件至 0.1.86-latest.0](https://github.com/KKUCODES/dshm-plugin/releases/tag/v0.1.86-latest.0)，然后重启 DSH。**中转服务无需升级，不修改 DSH 本体。** 此版不包含另一个开发分支的手机本地 npm 插件安装与通用插件宿主扩展。

518 项手机 Node、92 条原生兼容样例，以及三版原官方 CLI 经隔离中转连接 MuMu 的配对、工作区/空会话、重连、通知订阅和撤销检查通过；主题修复回归通过。用户报告的同步 CPU 死循环未独立复现，不能宣称已证明其具体根因。本轮未调用真实模型，也未全面复验 Electron、真机、公网及全部插件/审批/Office。附 SHA-256、签名及兼容元数据。

### What's changed

- Core Remote connectivity for official DSH **0.2.1-rc.2**, retaining **0.2.0-rc.2 / 0.2.1-alpha.2**.
- Bounded version ranges plus capability checks, shared platform modules, theme defaults and native notification compatibility.
- Pinned official rc.2 client SDK. Existing direct-chat providers, encrypted credentials, history and caches are retained.

Install **DSHM-0.1.0-preview.6.apk** over preview.1–preview.5 without uninstalling. Requires Android 9 or newer; application identity and signing certificate are unchanged. Update the desktop plugin to **0.1.86-latest.0** and restart DSH. No relay upgrade or DSH core modifications are needed. The separate plugin-adaptation branch is excluded.

518 Node tests, 92 native compatibility cases and isolated MuMu core-connection checks against three official CLI versions passed. The reported synchronous CPU loop was not independently reproduced. This release does not claim full Electron, physical-device, public-network, model or third-party-plugin validation.
