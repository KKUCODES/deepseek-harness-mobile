# DSHM 0.1.0-preview.21

- 修复 Remote 加载历史时，分页完成后的旧定位覆盖用户新滚动位置的问题；补齐最早一页加载按钮消失后的位移补偿。
- 补齐 DSH rc.3 的发送中状态判断，避免普通提示提前解除发送锁；发送失败后保留草稿并允许重试。
- 已通过连续历史加载、向更早消息滚动、重连与草稿保持回归，并在 MuMu 验证前后台切换后发送及回复。
- **已知限制：**尚未完整复现用户反馈的两类现场，不能保证本版已消除所有滚动回跳或切回前台无法发送的情况。如仍发生，请开启实时日志并保留出错时记录。
- 配套官方 DSH `0.2.2-rc.3` 与桌面插件 `0.1.88-latest.0`，插件无需额外更新。APK 使用原签名，直接覆盖安装可保留聊天、Key 和配对，请勿先卸载。

## English

- Fixed stale pagination anchors overriding the reader's new scroll position in Remote. Also corrected the shift when the history button disappears on the earliest page.
- Added the missing DSH rc.3 sending-state guard so ordinary notices cannot unlock an active submission. Failed submissions retain drafts and can be retried.
- Regression checks cover continuous history, scrolling toward older messages, reconnection, and drafts. Sending and replies after background/foreground transitions were verified in MuMu.
- **Known limitation:** the exact user-reported scenarios have not been fully reproduced. This release does not guarantee elimination of every scroll jump or foreground sending failure. If either persists, enable live logging and retain the records around the failure.
- Use official DSH `0.2.2-rc.3` with desktop plugin `0.1.88-latest.0`; no additional plugin update is required. The APK retains the existing signing certificate and supports in-place upgrades that preserve chats, keys, and pairing. Do not uninstall first.
