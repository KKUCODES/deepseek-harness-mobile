## 本次更新

- 新增 **App 内更新**：在「设置 → 软件更新」或「Remote → 连接选项 → 软件更新」检查新版，下载后由 Android 确认覆盖安装。启动时每天自动检查一次。
- 更新说明支持标题、列表、粗体、表格、代码块和链接。精简下载文案，将次要操作收进「更多」。已经是最新版时，也可查看本版说明。
- 包名、版本、签名、附件与校验失败分别说明原因；支持下载进度、取消和重试。保持原签名与应用数据，更新前不要卸载旧版。

## 安装

下载 **[DSHM-0.1.0-preview.8.apk](https://github.com/KKUCODES/deepseek-harness-mobile/releases/download/v0.1.0-preview.8/DSHM-0.1.0-preview.8.apk)**，Android 9 及以上可直接安装，或覆盖 preview.1–preview.7。

**旧版 App 尚无更新入口，请先手动安装本版。** 此后可在 App 内检查后续版本。首次安装更新时，需允许 DSHM 安装此来源的应用，再返回 App 点击安装；最终安装由系统确认。

Remote 继续配套 [电脑插件 0.1.87-latest.0](https://github.com/KKUCODES/dshm-plugin/releases/tag/v0.1.87-latest.0)，本次无需额外升级插件或中转。此前尚未完成长聊天分块升级的自建中转仍需包含协议提交 `94183d0`。不包含独立插件适配分支，不修改 DSH 本体。

本地 540 项手机测试、普通/Remote 页面及 Android 专项通过；同签名覆盖安装流程和 Markdown 说明已在模拟环境验证。不据此声明完整真机、所有厂商系统或全部 Remote 场景通过。

## What's changed

- **In-app updates** from Settings or the Remote connection menu, with daily automatic checks, download progress, cancellation, retry and Android-confirmed installation.
- Markdown release notes, fewer on-screen instructions and secondary actions under More. Release notes remain available when the app is up to date.
- Specific validation errors for package identity, versions, signing, assets and checksums. The existing app identity, certificate and data storage are retained.

Download **DSHM-0.1.0-preview.8.apk** for Android 9 or newer and install over preview.1–preview.7 without uninstalling. **Earlier public versions have no updater: install this version manually first.** Future updates can then be checked in the app. Android source permission and final installation confirmation remain under your control.

The companion desktop plugin remains **0.1.87-latest.0**. No additional plugin or relay upgrade is required for this release; relays that have not received the earlier large-response fix still need protocol commit `94183d0`. No DSH core changes or code from the separate plugin-adaptation branch.

540 local mobile tests and the ordinary/Remote UI and Android checks passed. Same-certificate installation and Markdown notes were verified in emulated environments; this is not a claim of complete physical-device, vendor or Remote coverage.
