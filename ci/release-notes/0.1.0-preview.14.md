## 本次更新

- **独立首页插件**：预装「Remote 新版首页」0.3.1，在「插件 → 手机」管理安装、外部文件更新、启停、卸载和恢复安装，按宿主实际运行情况显示状态。加载失败时回退默认首页。

- **插件历史读取兼容**：`loadOlder()` / `loadThrough()` 失败时保持官方接口行为；内部仍严格校验连续性，保留错误提示、原记录和重试能力，避免插件忽略 Promise 时出现未处理异常。
- 同步包含新版 Remote 连接页、连接诊断及上述能力所需的通用安装器、加载器与公开文档。

## What's changed

- **Independent home plugin**: Remote redesigned home 0.3.1 is preinstalled. Manage external file updates, enable/disable, uninstall and restore under **Plugins → Phone**. Status reflects actual host activation; failures fall back to the default home.
- **Keep user choices**: App upgrades do not resurrect uninstalled plugins or replace installed versions and enablement choices. Remote home API v1, an SDK, a template and developer documentation are included; arbitrary npm packages are not supported.
- **Theme and icons**: phone home, default fallback and app-owned dialogs follow the phone theme, including phone-light/desktop-dark combinations. Original Figma icons and SVG rendering on older Android WebViews are fixed.
- **Plugin history compatibility**: `loadOlder()` / `loadThrough()` preserve official failure semantics. Internal continuity checks, existing records, visible errors and retries remain strict, without unhandled rejections when plugins ignore the returned Promise.
- Includes the updated Remote connection page, diagnostics and the common installer/loader needed by these features.

Download **DSHM-0.1.0-preview.14.apk** for Android 9 or newer. Version code 22 keeps the existing application ID and signing certificate, allowing upgrades over prior public previews and local code 21 candidates while preserving chats, keys, pairing and plugin choices. **Do not uninstall first.**

The companion desktop plugin remains **0.1.87-latest.0**. No additional plugin or relay upgrade is required; self-hosted relays missing the earlier large-response fix still need commit `94183d0`. No DSH core changes or code from the old plugin-adaptation branch. **APK only; r2 is not published.**

First-time installation uses the bundled home plugin. Existing versions, disabled states and uninstall records take precedence. Local test users with an older home plugin can update from a file or explicitly uninstall and restore the version bundled in this APK.

596 Node tests, six history API cases per SDK and 24-batch history regressions passed with official DSH `0.2.1-rc.2` and `0.2.1-alpha.2`. Theme, original icons, lifecycle, fallback and preinstalled-package behavior were tested in two SDK page suites and MuMu. Synthetic history replay and earlier signed local candidates do not establish universal third-party plugin, real-user conversation or physical-device coverage.
