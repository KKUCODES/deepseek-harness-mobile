# DSHM 0.1.0-preview.23

## 中文

本版收录社区 [PR #1](https://github.com/KKUCODES/deepseek-harness-mobile/pull/1) 的后续改动，感谢 @lliangcode。Android 9 及以上可用原签名 APK 直接覆盖安装，保留本地聊天、设置和电脑配对。版本码为 33，Remote 配套桌面插件 `0.1.88-latest.0` 和官方 DSH `0.2.2-rc.3`。

- Remote 图片加载失败时可查看原因，对临时读取错误单独重试。会话出错时可展开原始错误详情。
- 文件面板的图片预览支持双指缩放、平移和双击。下载或分享完整文件时，打开「面板操作」菜单。
- 预装「Remote 新版首页」0.7.2。开启工作区分组后，点按首页标题或旁边的图标即可进入电脑连接页。

## English

This release includes the follow-up changes from community [PR #1](https://github.com/KKUCODES/deepseek-harness-mobile/pull/1). Thanks to @lliangcode. On Android 9 or later, install the APK over your existing copy to keep local chats, settings and computer pairing. The APK uses the existing signing certificate and version code 33. Use desktop plugin `0.1.88-latest.0` with official DSH `0.2.2-rc.3` for Remote.

- See why a Remote image failed to load and retry temporary read errors individually. Expand a failed chat turn to inspect the original error.
- Pinch, pan or double-tap images in the file preview panel. Open the panel actions menu to download or share the complete file.
- The bundled Remote home plugin is now 0.7.2. When workspace grouping is enabled, tap the home title or its icon to open the computer connection page.
