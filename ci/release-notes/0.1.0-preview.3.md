DSHM Android 开发预览版 / Android development preview

### 本次更新

- 为 Remote 页面、弹窗、面板和执行过程补齐过渡动画，支持系统减少动态效果。
- 改善工具记录、长错误、文件目录与内置面板的字号、间距和可用高度，减少手机上的重复缩放和裁切。
- 等待首段回复时显示“深度求索中”和原轮次用时，避免只有停止按钮、正文空白的等待状态。
- 分支改用 DSH 原图标，与点赞、点踩统一为 20px 图标、44px 点击区域和一致间距，跟随字号同步放大。

### 下载与更新

下载下方 **DSHM-0.1.0-preview.3.apk** 即可安装，最低 Android 9。保留原包名和签名，可直接覆盖更新 preview.1 / preview.2；请勿先卸载旧版，以免删除本地聊天与设置。

普通聊天使用你自己的 DeepSeek Key。Remote 继续支持官方 DSH **0.2.0-rc.2 / 0.2.1-alpha.2**，配套电脑插件 **0.1.84-latest.0** 和中转服务；电脑需保持运行。不需要修改 DSH 本体。

本次已有浏览器与 MuMu 验证；不代表所有物理手机、第三方插件或公网环境均已完成验收。附带 SHA-256、签名报告和兼容元数据。

### What's changed

- Smoother Remote navigation, dialogs, panels and execution disclosures, with reduced-motion support.
- More readable tool records, long errors, file lists and built-in panels on phone screens.
- A running indicator and elapsed turn time while waiting for the first response.
- The original DSH branch icon, with consistent reply-action icon sizes, touch targets and spacing.

Download the APK asset below; Android 9 or newer. Install over preview.1 / preview.2 to keep local data: the app identity and signing certificate are unchanged. Ordinary chat uses your own DeepSeek Key. Remote supports official DSH 0.2.0-rc.2 / 0.2.1-alpha.2 with desktop plugin 0.1.84-latest.0 and a relay. No DSH core patches are required.

Browser and MuMu checks do not replace full physical-device, third-party-plugin or public-network certification. SHA-256, certificate and compatibility reports are included.
