## 本次更新

- **统一软件更新界面**：APK与页面资源共用一个状态卡片和主按钮，下载进度、错误和下一步更清楚；更新说明、技术信息和恢复入口按需展开。
- **重启并应用**：兼容页面资源下载完成后，一键保存草稿、重启并自动返回原模式，无需去系统设置强行停止。发送中、保存失败或超时会取消重启，保留当前页面与待应用资源。
- 恢复APK内置页面也支持自动重启；升级APK后正常跳过已经过期的旧资源，不再误报为页面损坏。
- 保留聊天、Key、配对和设备身份，保留此前返回手势、长聊天分块及自定义供应商功能。

## 安装

下载 **[DSHM-0.1.0-preview.11.apk](https://github.com/KKUCODES/deepseek-harness-mobile/releases/download/v0.1.0-preview.11/DSHM-0.1.0-preview.11.apk)**，Android 9及以上可安装。沿用原包名和签名，versionCode为14，可覆盖preview.1–preview.10及本地preview.11-dev/code13。**请勿先卸载旧版。** preview.8及以上也可使用App内更新。

配套 [电脑插件 0.1.87-latest.0](https://github.com/KKUCODES/dshm-plugin/releases/tag/v0.1.87-latest.0) 保持不变，无需额外升级插件或中转；尚未完成此前长聊天分块升级的自建中转仍需包含提交`94183d0`。

本次只发布APK，**暂不发布r2页面资源包**；公共资源通道仍保留原r1。新APK会跳过仅兼容旧APK的r1，使用本版内置页面。不修改DSH本体，不包含独立插件适配分支。

550项本地Node测试、普通与Remote双入口页面和小屏布局通过；独立Android实际原生下载、验签、解压、保存失败保护、新进程启用资源、草稿保留及自动恢复通过。资源网络使用独立测试UID回放；不代表所有物理手机、厂商或已配对电脑的完整公网验收。

## What's changed

- **Unified software updates**: APK and page-resource updates share one status card and primary action. Release notes, technical details and recovery controls are collapsible.
- **Restart and apply**: after a compatible page-resource download, save drafts and automatically reopen the previous mode. Active sends, save failures or timeouts cancel the restart without losing pending resources.
- Restoring bundled pages also restarts automatically. APK upgrades skip expired resource packages instead of reporting page corruption.
- Preserve chats, keys, pairing and device identity, including earlier navigation, large-response and custom-provider fixes.

Download **DSHM-0.1.0-preview.11.apk** for Android 9 or newer. Version code14 uses the existing application ID and certificate and can replace preview.1–preview.10 or local preview.11-dev/code13. **Do not uninstall first.** preview.8 and newer support in-app APK updates.

The companion desktop plugin remains **0.1.87-latest.0**. No additional plugin or relay upgrade is required; self-hosted relays missing the earlier large-response fix still need commit`94183d0`.

**APK only; r2 is not published.** The public resource channel keeps r1. This APK skips that older APK-only resource package and uses its new bundled pages. No DSH core changes or code from the separate plugin-adaptation branch.

550 local Node tests, both page entries and small-screen layouts passed. Isolated Android checks cover real native download, signature verification, extraction, save-failure protection, restart, activation, retained drafts and recovery with replayed resource responses. These do not establish complete physical-device or paired public-network coverage.
