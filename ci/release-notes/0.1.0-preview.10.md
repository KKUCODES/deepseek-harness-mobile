## 本次更新

- 新增**完整页面资源热更新**：在「软件更新 → 页面资源」检查和下载，校验完成后在下次完整启动时启用。切换页面或返回前台不会立即替换正在使用的资源。
- 资源包使用独立签名，校验 APK 版本范围、桥接口、数据版本、SDK、配套插件及文件摘要；不兼容或校验失败时保留原资源。
- 页面启动失败会在下次启动回退到上一可用包或 APK 内置页面；原生「恢复内置页面」入口不依赖页面正常运行。
- 保留聊天、草稿、Key、配对及设备身份。涉及原生功能、权限或不兼容接口的更新仍通过 APK 完成。

## 安装

下载 **[DSHM-0.1.0-preview.10.apk](https://github.com/KKUCODES/deepseek-harness-mobile/releases/download/v0.1.0-preview.10/DSHM-0.1.0-preview.10.apk)**，Android 9 及以上可直接安装，或覆盖 preview.1–preview.9。保持原包名和签名，**请勿先卸载旧版**。

preview.8、preview.9 用户可通过 App 内更新下载本版；更早版本请手动覆盖安装。**需要先升级本版 APK 一次，之后才能接收兼容的页面资源包。**本次发布加载器及其内置资源，暂不投放重复的页面资源更新包。

配套 [电脑插件 0.1.87-latest.0](https://github.com/KKUCODES/dshm-plugin/releases/tag/v0.1.87-latest.0) 保持不变。本版无需额外升级插件或中转；尚未完成此前长聊天分块升级的自建中转仍需包含提交 `94183d0`。不修改 DSH 本体，不包含独立插件适配分支。

545项本地Node测试、双入口页面回放、Android签名互通与真实资源加载/故障回退/恢复内置页验收通过。Android专项使用独立API36设备和网络响应回放；不代表所有真机、厂商或真实已配对电脑公网验收。

## What's changed

- Add **signed full page-resource updates** under Software updates → Page resources. Downloaded resources activate on the next full process launch, keeping the current session on one resource version.
- Verify the independent signature, APK compatibility range, bridge/data versions, SDK, companion plugin and file hashes before activation.
- Recover from startup failures on the next launch using a previous healthy resource set or bundled pages. A native recovery entry remains available even when page code fails.
- Preserve chats, drafts, keys, pairing and device identity. Native functionality, permissions and incompatible interfaces still require an APK update.

Download **DSHM-0.1.0-preview.10.apk** for Android 9 or newer. Install over preview.1–preview.9 without uninstalling. preview.8/preview.9 users can use the in-app updater. **Install this APK once to enable future compatible page-resource updates.** No redundant resource update is being published with this release.

The companion desktop plugin remains **0.1.87-latest.0**. No additional plugin or relay upgrade is required; self-hosted relays missing the earlier large-response fix still need commit `94183d0`. No DSH core changes or code from the separate plugin-adaptation branch.

545 local Node tests, both page-entry replays, Android signature interoperability, real resource loading and recovery checks passed. Android checks used an isolated API36 device with replayed network responses; they do not establish complete physical-device or paired public-network coverage.
